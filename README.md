# Watson Task Board

Personal task manager with workspace switching, priority queues, and file-based local storage.

**Live app:** https://fansi129.github.io/ToDoApp/

## Features

- **Workspaces → Projects → Milestones → Tasks** hierarchy
- **File System Access API** — tasks stored as individual JSON files on your machine, nothing uploaded anywhere
- **Time filters** — Overdue / Today / 3 Days / Week / All
- **Recurring tasks** — Daily, Weekly, Biweekly, Monthly — auto-spawns next occurrence on complete
- **Priority groups** — P1 Critical → P4 Low with drag-to-reorder within group
- **Up Next card** — always shows your highest priority open task
- **Keyboard shortcuts** — `W` sidebar · `1–9` switch workspace · `N` new task · `/` search

## Requirements

Chrome or Edge (requires File System Access API). First visit: pick a local folder to store tasks. Subsequent visits: one-click resume.
